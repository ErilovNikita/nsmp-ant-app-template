# FullForm
`FullForm` - демонстрационный компонент комплексной формы. Он показывает, как собрать форму из контроллеров, UI-компонентов, кэша, проверки версии и панели текущих значений.

## Общая структура
Компонент разделен на две колонки:

- левая колонка содержит форму ввода;
- правая колонка содержит alert версии, группу текущих значений формы и отладочный блок с данными кэша.

Разметка построена на `a-row` и `a-col`.

## Контроллеры
В форме используются:

- `DropdownFieldObjectController` для асинхронного выбора сотрудника из API;
- `DropdownFieldDictionaryController` для локальных списков и radio-значений;
- `AlertController` для сообщений формы, описания поля и проверки версии;
- `AttrGroupController` для вывода значений формы и содержимого кэша.

## Поля формы
Форма работает с `DefaultFormState` из `src/domain/config.ts`.

| Поле | Компонент | Назначение |
| --- | --- | --- |
| `someTextWithLoader` | `a-select` | Локальный выпадающий список с поиском. |
| `someTextWithDescription` | `a-input` | Текстовое поле с информационным alert и required-валидацией. |
| `number` | `a-input-number` | Числовое поле с ограничением от 1 до 10. |
| `dropdownList` | `a-select` | Асинхронный выбор сотрудника из API. |
| `simpleCheckbox` | `a-checkbox` | Логическое значение. |
| `onceSelect` | `a-radio-group` | Выбор одного значения из локального списка. |
| `slider` | `a-slider` | Числовое значение с шагом 5. |
| `rangePicker` | `a-range-picker` | Диапазон дат в формате `YYYY-MM-DD`. |

## Валидация и submit
Форма использует стандартные события Ant Design Vue:

- `@finish="finish"` - успешная отправка;
- `@finishFailed="onFinishFailed"` - ошибка валидации.

Сейчас submit демонстрационный: он не отправляет данные на сервер, а показывает alert с результатом.

## Кэш формы
Кэш подключается через:

```ts
const { formattedCachedData, restoreCacheAlert, restoreCachedData } = useFormCache(formState)
```

`useFormCache`:

- проверяет localStorage при первом открытии;
- показывает alert восстановления, если в кэше есть данные;
- сохраняет изменения формы;
- возвращает форматированный JSON для блока "Данные в кеше".

Alert восстановления расположен сверху формы. Кнопка `Восстановить` вызывает `restoreCachedData()` и переносит значения из кэша в поля.

## Проверка версии
Компонент получает последний release tag через GitHub API:

```ts
getLastReleaseTag(GitProject.owner, GitProject.repo)
```

Затем `compareVersions()` сравнивает удаленную версию с локальной `__APP_VERSION__`. Результат выводится через `versionController`:

- `success` - версия актуальна;
- `warning` - локальная версия выше release tag, вероятно используется тестовая сборка;
- `error` - локальная версия устарела или проверка завершилась ошибкой.

## Правая панель
Правая панель содержит:

- alert версии;
- `AttrGroup` с текущими значениями формы;
- `AttrGroup` с JSON-представлением кэша.

Для длинного JSON используется отдельный styled-блок с прокруткой.
