# AttrGroup
`AttrGroup` отображает группу атрибутов в `a-collapse`. Компонент используется для компактного вывода текущих значений формы или связанных данных.

## Props
| Prop | Тип | Описание |
| --- | --- | --- |
| `config` | `AttrGroupController` | Контроллер заголовка, активной панели и списка атрибутов. |
| `values` | `any` | Объект, из которого берутся значения атрибутов. |

## Формат `items`
`config.items.value` должен быть массивом пар:

```ts
Array<[label: string, fieldName: string]>
```

Первый элемент пары становится label в `a-form-item`, второй используется как ключ для чтения значения из `values`.

```ts
const group = new AttrGroupController('Основные данные', [
  ['Имя', 'name'],
  ['Возраст', 'age'],
]).open()
```

```vue
<AttrGroup :config="group" :values="formState" />
```

Если `formState.name = 'Nikita'`, компонент выведет строку `Имя: Nikita`.

## Slots
| Slot | Описание |
| --- | --- |
| `start` | Контент перед автоматически сгенерированными атрибутами. |
| `end` | Контент после автоматически сгенерированных атрибутов. |

Slot `end` удобен для нестандартного отображения значений, например диапазона дат или JSON-блока кэша:

```vue
<AttrGroup :config="group" :values="formState">
  <template #end>
    <a-form-item label="Дата начала">
      <a-typography-text>{{ formState.rangePicker?.[0] }}</a-typography-text>
    </a-form-item>
  </template>
</AttrGroup>
```

## Layout
Внутри используется горизонтальная форма с шириной label `225px`. Это хорошо подходит для боковой панели с короткими значениями. Если значение длинное, лучше выводить его через slot `end` и задавать локальные стили.

## Ограничения
- Компонент не форматирует значения: он выводит `values[fieldName]` как есть.
- Для массивов, объектов и сложной разметки используйте slot.
- Ключи из `items` должны существовать в `values`, иначе будет выведено пустое значение.
