# AttrGroupController
Управляет группой атрибутов или секцией формы.

## Свойства
| Свойство | Тип | Описание |
| --- | --- | --- |
| `title` | `Ref<string>` | Заголовок группы |
| `show` | `Ref<boolean>` | Открыта ли группа |
| `activeKey` | `Ref<number \| null>` | Активная панель |
| `items` | `Ref<Array<[string, string]>>` | Элементы группы |

## Методы
| Метод | Описание |
| --- | --- |
| `open()` | Открывает группу |
| `close()` | Закрывает группу |
