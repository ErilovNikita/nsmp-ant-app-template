# ModalController
Управляет модальными окнами.

## Свойства
| Свойство | Тип | Описание |
| --- | --- | --- |
| `title` | `Ref<string>` | Заголовок модального окна |
| `visiable` | `Ref<boolean>` | Показывается ли окно |

## Методы
| Метод | Описание |
| --- | --- |
| `show()` | Показывает окно |
| `hidden()` | Скрывает окно |
