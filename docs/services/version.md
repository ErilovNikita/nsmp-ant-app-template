# Version service
`src/services/version.ts` содержит функции для работы с версией приложения.

## `compareVersions(localVersion, remoteVersion)`
Сравнивает две версии в формате `major.minor.patch`.

```ts
compareVersions('1.2.0', '1.3.0') // -1
compareVersions('1.3.0', '1.3.0') // 0
compareVersions('1.4.0', '1.3.0') // 1
```

Возвращаемые значения:

| Значение | Значение сравнения |
| --- | --- |
| `-1` | Локальная версия меньше удаленной. Приложение устарело. |
| `0` | Версии равны. Приложение актуально. |
| `1` | Локальная версия больше удаленной. Обычно это тестовая или prerelease-сборка. |

Функция сравнивает первые три числовых сегмента. Если сегмента нет, он считается равным `0`: `1.2` будет обработано как `1.2.0`.

## `getLocalVersion()`
Возвращает локальную версию приложения из глобальной константы `__APP_VERSION__`.

Эта константа задается в `vite.config.ts`:

```ts
define: {
  __APP_VERSION__: JSON.stringify(pkg.version),
}
```

Источник значения - поле `version` в `package.json`.

## Сценарий использования
В `FullForm.vue` сервис используется вместе с GitHub release tag:

1. `getLastReleaseTag()` получает последнюю опубликованную версию.
2. `getLocalVersion()` возвращает версию текущей сборки.
3. `compareVersions()` определяет статус.
4. `AlertController` показывает пользователю результат.

Так можно предупредить пользователя, что он работает с устаревшей версией и ему нужно сбросить кэш браузера.
