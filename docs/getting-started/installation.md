# Установка
```sh
git clone https://github.com/ErilovNikita/nsmp-ant-app-test.git
cd nsmp-ant-app-test
npm install
npm link @nsmp/js-api
npm run dev
```

## Требования
- Node.js и npm.
- Доступная локально библиотека `@nsmp/js-api`.
- Настроенный `.env` по образцу `example.env`.

## Команды
```sh
npm run dev
npm run build
npm run preview
```
